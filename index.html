Pray For Nepal: DOM Clobbering to Flag

DOM Clobbering Reflected XSS Client-Side Gate

Introduction

The “Pray For Nepal — Missing Person Registry” challenge reflects the person query parameter into the page. A client-side sanitizer removes dangerous tags and event handlers, and a gate only loads a script when two specific DOM elements exist with exact attributes. The goal is to trigger alert(document.domain), which the page overrides to fetch /reveal.php and display the flag.

Original landing page + Network

The Gate

After inserting the user-controlled HTML, the page checks for:

  • #archive-latch with data-key="river-lantern"
  • #record-anchor with data-index="/echo.php?channel=echo&listener=alert(document.domain)//"

If both match, it creates a same-origin script tag. The CSP allows 'self', so the script loads. /echo.php reflects the listener value as JavaScript. The overridden window.alert then POSTs to /reveal.php.
